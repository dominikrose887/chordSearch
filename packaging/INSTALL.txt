Chord Search 1.0.3 - Windows x64
================================

Option A - Installer (recommended)
----------------------------------
Run ChordSearch-Setup-1.0.3.exe
- Pick the install folder
- Start Menu shortcut + uninstaller are created
- Remove via Windows Settings > Apps, or the Start Menu uninstall entry

Option B - Portable (no install)
--------------------------------
1. Unzip ChordSearch-*-win-x64-portable.zip anywhere
2. Keep portable.txt next to ChordSearch.App.exe
3. Run ChordSearch.App.exe
   Settings / tunings / logs are stored in a Data folder beside the exe.

Requirements
------------
- Windows 10/11 x64
- Self-contained (no separate .NET install)
- MIDI device optional (for Play / Arpeggio)

Docs: https://github.com/dominikrose887/chordSearch
